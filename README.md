# Farmer Subsidy Management System

## Project Description
Farmer Subsidy Management System is a web application developed using Flask and MongoDB. It allows farmers to register, log in, apply for subsidies, and track their application status. The administrator can view all applications and approve subsidy requests.

## Features
- Farmer Registration
- Farmer Login
- Apply for Subsidy
- View Subsidy Status
- Admin Login
- Admin Dashboard
- Approve Subsidy Applications
- MongoDB Integration

## Technologies Used
- Python
- Flask
- MongoDB
- HTML
- CSS

## Installation

```bash
pip install -r requirements.txt
python app.py
```
